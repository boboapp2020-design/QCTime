# QC Time — Mitr Lao Sugar

ระบบงานควบคุมคุณภาพน้ำตาล: ค้นหา Lot · จ่ายออกน้ำตาล · ออกใบ COA

เว็บแอปไฟล์เดียว (`index.html`) + โฟลเดอร์ `assets/` เปิดผ่าน GitHub Pages ได้ทันที

## Deploy (GitHub Pages)
1. อัปทุกไฟล์ในโฟลเดอร์นี้ขึ้น repo (คงโครงสร้าง `assets/` ไว้)
2. Settings → Pages → Branch: `main` /(root) → Save
3. เปิดที่ `https://<username>.github.io/<repo>/`
